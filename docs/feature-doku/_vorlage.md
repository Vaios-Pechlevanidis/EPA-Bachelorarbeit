## 1. Vorstellung

Was sieht die Nutzerin oder der Nutzer im Dashboard? Wo liegt das Feature, was kann
man damit tun? Ein Satz zum Nutzen. Screenshot optional unter `bilder/`.

## 2. Erklärung

Wie entsteht das Ergebnis, Schritt für Schritt von den Daten bis zur Anzeige?
Welche Parameter gibt es, mit welchen Startwerten? Fachbegriffe mit Herkunft erklären.

## 3. Begründung

Warum dieses Verfahren, diese Darstellung, diese Werte? Welche Alternativen gab es und
warum wurden sie nicht gewählt? Bezug zu Anforderungen, Entscheidungen und Literatur.

## 4. Grenzen

Was kann das Feature nicht? Wofür reichen die Daten nicht? Was darf man daraus nicht
schließen?
